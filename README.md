# Customer Segmentation Using K-Means Clustering

## Overview

Customer Segmentation is a Machine Learning project that groups customers based on their purchasing behavior. Using K-Means Clustering, customers are segmented according to their Annual Income and Spending Score, helping businesses understand customer patterns and create targeted marketing strategies.

## Problem Statement

Businesses often have a large customer base with varying spending habits. Identifying customer groups allows organizations to:

* Improve customer retention
* Create personalized marketing campaigns
* Increase sales and revenue
* Understand customer behavior patterns

## Dataset

The project uses the Mall Customers dataset containing:

* Customer ID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1–100)
